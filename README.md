# Portfólio Pessoal – Pedro Augusto Santos Brito

## Sobre o Projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal com o objetivo de apresentar minha trajetória acadêmica, habilidades, conhecimentos e projetos desenvolvidos na área de tecnologia.

O site foi criado como atividade prática da disciplina de **Interface Homem-Máquina (IHM)**, do curso de **Análise e Desenvolvimento de Sistemas**, no Instituto Federal Baiano – Campus Guanambi.

A proposta é apresentar uma interface moderna, intuitiva e organizada, proporcionando uma navegação simples e agradável aos visitantes.

## Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar e organizar os elementos e conteúdos do site.
- **CSS3:** utilizado para estilizar a interface, definir cores, fontes, espaçamentos e organizar os elementos do layout.

## Estrutura do Projeto

- **ihm.html:** arquivo responsável pela estrutura principal da página.
- **style.css:** arquivo responsável pela estilização e aparência visual do site.
- **Imagem/:** pasta destinada ao armazenamento das imagens utilizadas no portfólio.

## Características da Interface

- Design moderno e minimalista.
- Identidade visual baseada em tons escuros.
- Organização dos conteúdos em seções.
- Menu de navegação para facilitar o acesso às informações.
- Layout desenvolvido com foco na organização e experiência do usuário.
